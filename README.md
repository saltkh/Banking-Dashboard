# Banking Dashboard

An iOS banking dashboard app built in **Swift** and **SwiftUI**, showcasing UI design skills with a clean, modern financial interface.

---

## Features

- Account balance overview
- Transaction history list with categories
- Income vs spending summary
- Responsive SwiftUI layout built for iPhone

---

## Tech Stack

| | |
|---|---|
| Language | Swift |
| UI Framework | SwiftUI |
| Data | Mock data (local) |
| Architecture | MVVM |

---

## Getting Started

### Prerequisites
- Xcode 15+
- iOS 17+ simulator or device

### Run

1. Clone the repo
```bash
git clone https://github.com/saltkh/Banking-Dashboard.git
```

2. Open the `.xcodeproj` file in Xcode

3. Run on simulator with `Cmd + R`

No API keys or external dependencies required — the app uses local mock data.
